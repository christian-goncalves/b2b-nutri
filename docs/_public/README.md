# Capas e amostras do catálogo

- Capas finais usadas pelo catálogo: [`web/public/images/books/`](../../web/public/images/books/).
- PDFs públicos de amostra, com cinco páginas: [`web/public/samples/`](../../web/public/samples/).
- Imagens WebP usadas pelo leitor: [`web/public/samples/pages/`](../../web/public/samples/pages/). O atalho local [`amostras-ebooks`](amostras-ebooks) abre esse diretório.
- PDFs completos de origem: [`ebooks/`](../../ebooks/). Permanecem fora de `web/public/`.

O diretório contém apenas o atalho `amostras-ebooks` para as páginas visuais das amostras.
